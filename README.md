# Проект "Веб-стор"

## Описание
Проект "Веб-стор" - это небольшое приложение для интернет - магазина различных продуктов

## Установка

1. Клонируйте репозиторий
git clone https://github.com/ksen6423/oopproject.git
2. Установите зависимости
pip install -r requirements.txt
 
## Использование

1. Зайдите в приложение
2. Выберите нужные категории
3. Выведите количество продуктов в категориях
4. Добавьте и сложите продукты в разных категориях
5. Распечатайте информацию о параметрах объекта

## Использование классов
1. Классы Product и Category, содержащие информацию о названии, описании, ценах и количестве продуктов
2. Класс-наследник Smartphone, содержащий информацию о производительности, модели, объеме встроенной памяти и цвете продукта
3. Класс-наследник LawnGrass, содержащий информацию о стране-производителя, сроке прорастания и цвете продукта

## Тестирование

Запуск тестов с помощью pytest (установка pip install pytest):
1. python -m pytest (все тесты в проекте)
2. python -m pytest/test_product.py (конкретный файл)

Запуск тестов с помощью unittest (встроенный фреймворк)
1. import unittest
2. python -m unittest discover (выполнение всех тестов в проекте)

Общее покрытие тестами 90%
